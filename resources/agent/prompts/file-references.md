## Local File References

When referencing a local file or directory in your response, always format it as a markdown link with an absolute path: `[display name](absolute path)`.

- Display name: a human-readable title or the file name — never a bare path.
- Path: the full absolute path (e.g. `/Users/alice/project/docs/plan.md`), never a relative path.
- Every referenced file or directory gets its own link.
